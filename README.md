🚀 Multipurpose Logic Hub & Portfolio Dashboard

A high-performance, modular React.js application designed to serve as a centralized hub for utility tools, mathematical engines, and security protocols. This project showcases the power of component-based architecture and dynamic state management.

✨ Project Highlights & Modules
The dashboard integrates 10+ functional modules, each built as an independent component:

🔐 Login Portal: A professional login interface with validation and social auth simulation.

📝 Registration: Optimized registration & user validation flow.

🧮 Calculator: Advanced arithmetic operations with a sleek UI.

🔢 Live Counter: Real-time state management and interaction tool.

🔄 Palindrome: Logical engine to check for mirror-image strings (Palindromes).

🧪 Prime Tester: Mathematical validation for prime numbers.

🌦️ Weather App: Live atmospheric data fetcher using external API logic.

⏱️ Stop watch: Millisecond-accurate stopwatch for performance tracking.

📍 Google Map: Interactive geographic mapping and location display.

🌓 Theme Switcher: Dynamic theme toggle for Light and Dark modes.

🛠️ Technical Stack
Frontend: React.js 

Styling: Custom CSS3 with CSS Variables for theme management.

Version Control: Git & GitHub.

🚀 Key Features
Execute Hub Logic: Each module is executed within a professional modal system to keep the dashboard clutter-free.

Responsive Design: Fully optimized for desktops and tablets using CSS Flexbox and Grid.

Social Auth Simulation: Integrated Google and GitHub login UI for a realistic application feel.

Dark Mode Aesthetic: Built with a modern, high-contrast dark theme (GitHub-inspired palette).
